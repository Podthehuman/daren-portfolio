# Certificate gallery

The portfolio reads `certificates.json` automatically.

## Add a certificate
1. Put the PDF/JPG/PNG in this folder.
2. Add one object to `certificates.json`:
   `{"title":"Course title","file":"exact-filename.pdf","category":"cybersecurity","issuer":"Issuer"}`
3. Commit and push to GitHub.

Allowed categories: `data`, `cybersecurity`, `software`, `web`, `it`, `other`.

No changes to `index.html` are required.
